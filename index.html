NekoBet

Integridad transaccional y APIs B2B

  • Plataforma para puntos de venta (apuestas en vivo, casino y recargas desde un mismo saldo) con React, NestJS, TypeScript y PostgreSQL, ledger append-only e idempotencia obligatoria.
  • Un UPDATE condicional con restricción CHECK evita sobregiros bajo concurrencia: en un experimento local, de 70 ventas simultáneas con saldo para 50 se aprobaron exactamente 50.
  • API B2B firmada con HMAC-SHA256 (cuerpo y clave de idempotencia), con ventana antirrepetición, comparación en tiempo constante y lista blanca de IP (CIDR).
  • 69 pruebas automatizadas (24 unitarias, 45 de integración) en CI con CodeQL, Trivy y OWASP ZAP.

NekoBet

Transaction integrity and B2B APIs

  • Point-of-sale platform (live sports bets, casino and top-ups from one balance) built with React, NestJS, TypeScript and PostgreSQL, with an append-only ledger and mandatory idempotency keys.
  • A conditional UPDATE with a CHECK constraint prevents overspending under concurrency: in a local experiment, 70 concurrent sales against room for 50 approved exactly 50.
  • Partner B2B API signed with HMAC-SHA256 (body and idempotency key), with a replay window, constant-time comparison and a CIDR IP allowlist.
  • 69 automated tests (24 unit, 45 integration) in CI with CodeQL, Trivy and OWASP ZAP.
